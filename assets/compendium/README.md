# Kompendium - Rozszerzone Opisy

Ten folder zawiera rozszerzone opisy mechanik, ścieżek, zaklęć i innych elementów dla różnych systemów RPG w formacie Markdown.

## Systemy

### [Shadow of the Demon Lord / Cień Władcy Demonów](shadow_demon_lord/)

Pełne opisy ścieżek mistrzowskich, tradycji magii, zaklęć i pochodzeń.

---

## Struktura

Każdy system ma swój podfolder z odpowiednią strukturą:

```
compendium/
├── shadow_demon_lord/
│   ├── README.md
│   ├── pochodzenia/
│   ├── sciezki_eksperckie/
│   │   └── wyrocznia.md
│   ├── sciezki_mistrzowskie/
│   ├── tradycje_magii/
│   ├── zaklecia/
│   └── artefakty/
└── [inne systemy...]
```

## Dodawanie nowych opisów

1. Wybierz odpowiedni system i kategorię
2. Utwórz plik `.md` z nazwą elementu
3. Użyj formatowania Markdown dla czytelności
4. Zaktualizuj odpowiedni README.md z linkiem
