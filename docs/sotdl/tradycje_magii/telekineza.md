# Telekineza

**Zrodlo:** Suplement Władcy Demonów, str. 41

**Atrybut: Intelekt**

Poznanie tradycji Telekineza oznacza przebudzenie psychicznych umiejętności, które pozwalają poruszać i manipulować obiektami i stworzeniami dzięki mocy umysłu. Magia tą można odepchąć wrogów, podnieść ciężkie przy użyciu niewidzialnej siły.

Wpleccie osób uczy się Telekineze po doświadczeniu jakiegoś rodzaju psychicznego bólu lub obciążenia. Okropna rana, śmierć kogoś bliskiego albo inny traumatyczny świadków - wszystko może zakalić umysłowe bariery związane z ukrytą mocą.
