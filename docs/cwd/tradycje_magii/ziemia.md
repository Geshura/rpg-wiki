# Ziemia

**Zrodlo:** Podręcznik Główny, str. 151

**Atrybut: Wola**

Magia Ziemi czerpie moc z gleby, skył i mineralów. Pozwala na wywoływanie trzesień ziemi, tworzenie kamiennych murów i zmianę struktury terenu. Jest to solidna i potężna magia, często używana przez krasnoludy, górników i budowniczych.

Użytkownicy Magii Ziemi są często postrzegani jako osoby twarde i niewzruszone. Mogą mieć skórę przypominającą kamień lub oczy w kolorze ślachetnych kamieni. Czasem, gdy się poruszają, słychać chrzęst żwiru lub pękanie skął.
